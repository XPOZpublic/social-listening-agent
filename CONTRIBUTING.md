# Contributing

Fixes and small improvements are welcome: a clearer report contract, better search passes, new tools over the SDK.

Ground rules: keep it minimal and runnable from a fresh clone; no comments in code, clear names instead; snake_case; no em or en dashes in prose; pricing and scale statements stay in the durable framing the README uses.

Test a change by running one real report with a Free tier key before opening a PR, and say in the PR what you ran.
